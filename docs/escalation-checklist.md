# Meeting-Room Escalation Checklist

- [ ] Room and asset identifiers recorded
- [ ] Meeting platform and start time recorded
- [ ] User impact and workaround recorded
- [ ] Exact symptoms and error text captured
- [ ] Power, source, display, audio, camera and USB path checked
- [ ] Known-good comparison attempted when authorised
- [ ] Network and service status checked
- [ ] Actions and result of each action documented
- [ ] Configuration changes avoided or recorded
- [ ] Security or privacy concern flagged immediately
- [ ] Correct resolver group and precise assistance required stated
