# Teams and Zoom Diagnostic Workflow

## Calendar or join failure

Check room-resource booking, time/date, network/DNS, room-account state and service health. Do not bypass access policy or request user credentials.

## No camera

Confirm privacy shutter and power, selected camera, USB path, application permission and whether another application holds the device. Compare with a known-good port or cable.

## No microphone

Confirm mute state, selected input, input level, USB/DSP path and application permission. Use a local test and avoid recording real meeting content.

## No room audio

Confirm selected output, display/DSP/amplifier path, mute and level, HDMI/USB routing and whether local system audio works. Change one variable at a time.

## Sharing failure

Separate cable/adapter, source-device, display-input, resolution/HDCP and platform-permission issues. Record which combinations work.

## Escalation boundary

Escalate tenant policy, room-account licensing, firmware, network segmentation, certificate, DSP programming and multi-room failures to the authorised owner.
